# 埃及车辆违章查询

独立的一体化桌面程序，与 Chrome/Edge 商店插件完全分离。打开一个程序即可同时获得：

- 桌面 GUI
- 手机端响应式 Web 页面
- 查询 API 和 SSE 实时进度
- 单任务查询队列、去重、超时与熔断
- SQLite 完整查询档案和逐步事件时间线
- 脱敏 JSONL 审计日志
- 同端口、密码保护的远程 Admin 管理后台（桌面 GUI 可免密进入）
- 用户建议反馈、设备/IP 审计与粗略 IP 归属信息
- 查询页与 Admin 共用的中文/英文、亮色/暗色主题偏好
- 可公开查看的服务器/PPO 官网服务状态面板
- Electron 内置 Chromium/PPO 会话

不需要 PM2，也没有需要分别启动的前端、后端服务。

## macOS 菜单栏与后台运行

程序启动后会在 macOS 顶部菜单栏显示常驻图标。点击窗口最小化按钮或左上角关闭按钮时，只隐藏主窗口和 Dock 图标，查询服务、队列及手机访问地址继续运行；双击菜单栏图标或选择“显示主窗口”即可恢复。只有选择菜单里的“退出程序并停止服务”才会真正关闭服务。

菜单栏提供：

- 显示或隐藏主窗口
- 用系统默认浏览器打开用户页面
- 用系统默认浏览器打开需要密码登录的 Admin 页面
- 复制当前访问地址
- 开启或关闭开机自动启动；登录启动时默认只驻留菜单栏，不主动弹出窗口
- 检查 GitHub 最新 Release、打开新版下载页
- 显示当前程序版本、服务端口和运行状态
- 完全退出程序并安全停止服务

程序启用了单实例保护。重复打开 App 不会另起服务或占用新端口，而是唤醒当前正在运行的窗口。开机自启开关只在打包后的正式 App 中开放，避免开发模式把 Electron 开发运行环境误注册为登录项。

## 开发运行

开发环境要求 Node.js 22.5+。安装后的程序直接使用 Electron 内置 Chromium，不要求用户另外安装 Google Chrome 或 Microsoft Edge。

```bash
cd /Users/dragon/ppo-traffic-autofill/desktop-app
npm install
npm test
npm start
```

`npm start` 会直接打开桌面窗口，并在程序内部启动 Web/API 服务。关闭程序时，服务和查询浏览器会一并关闭。

查询前，程序会先保留 PPO/WAF Cookie、清理上一轮页面存储并重新进入官方查询页，然后按“车辆牌照违章页签可见 → 字母车牌表单可见 → APEX 单选与动态字段完成 → 精确识别字母车牌查询按钮”的顺序初始化。任何阶段都有固定等待上限，不会反复刷新或无限查询。

## 手机访问

桌面窗口会显示手机访问地址，例如：

```text
http://192.168.1.20:17654
```

程序固定监听 `0.0.0.0`。手机与电脑处于同一局域网时，可通过电脑的局域网 IP 加端口访问。程序不在页面中探测或展示局域网 IP。程序优先使用 `17654`；如果端口已被其他程序使用，会自动尝试 `17655`～`17663`，不会停止或覆盖现有服务。

页面标题旁会显示浏览器当前实际使用的访问地址和端口。本机或局域网访问时显示当前 IP 地址和程序端口；通过公网域名或反向代理访问时，以浏览器地址栏为准显示 `https://域名`，且不向公网用户展示内部服务端口。

页面右上角提供中英文和亮暗主题切换。首次访问默认使用中文，主题跟随设备系统设置；用户手动切换后会保存在当前浏览器，并在查询页与 `/admin` 之间同步。语言切换覆盖表单、状态、校验提示、队列进度、历史查询时间线和管理后台界面；已有数据库记录中的初始化过程、提交步骤和护照格式重试说明也会在英文界面动态翻译。用户反馈、PPO 官网原始提示与审计日志继续保持原文，便于准确追溯。

车牌表单和服务端统一支持 **2～3 个阿拉伯字母**、**1～8 位纯 0–9 数字**，因此两字母四数字（例如 `أ ف 3413`）可直接查询；第三个字母留空即可。服务端会再次执行同样校验，外部 API 也遵循这一规则。

防火墙需要允许本程序接收局域网连接。公网发布时建议通过 Cloudflare Tunnel 或反向代理连接桌面程序，避免直接在路由器上暴露端口。

## 打包

```bash
npm run build
```

macOS 生成 DMG/ZIP，Windows 生成安装包和便携版。打包结果位于 `dist/`。

仓库根目录的 GitHub Actions 会在每次推送到 `main` 时自动构建 Chrome、Edge 和 macOS Universal 产物；推送与扩展版本一致的 `v*.*.*` 标签时，还会自动创建 GitHub Release。macOS 正式对外分发建议在 GitHub 仓库的 Actions Secrets 中配置：

- `MAC_CSC_LINK`：Developer ID Application 证书的 base64 或私密下载地址
- `MAC_CSC_KEY_PASSWORD`：证书密码
- `APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`：Apple 公证凭据

没有这些 Secrets 时 CI 仍可生成 DMG/ZIP，但 macOS 可能提示应用来源未经验证；完成签名和公证后才适合直接提供给普通用户安装。

## 匿名访问和流控

Web 页面不需要账号密码。匿名查询默认受到以下保护：

- 单 IP 每分钟 2 次
- 单 IP 每日 30 次
- 同一浏览器设备 25 秒冷却
- 相同参数 2 分钟内复用原任务
- 全局队列最多 10 个任务，满后返回稍后重试提示
- 排队超过 15 分钟的任务自动安全终止，避免陈旧请求突然执行
- 连续 5 次官网基础设施故障后暂停接收新查询 5 分钟
- 查询单次等待上限 45 秒
- 护照格式最多切换一次，不会无限重试
- SSE 实时连接默认最多 100 个
- 同一 IP 最多保持 5 个 SSE 连接，包含格式错误在内的提交最多 10 次/分钟
- 同一 IP 与设备组合每小时最多提交 3 条、每日最多 10 条建议反馈

参数可参考 `.env.example` 中对应的环境变量调整。公网开放时建议增加按风险触发的 Turnstile 人机验证。

公开健康检查和队列接口只返回任务数量、容量及当前设备自己的脱敏状态，不返回完整请求。普通 Web 用户的历史、详情、取消操作和相同任务复用均按随机设备标识隔离；全局记录只对携带有效 API Key 的受信任调用及桌面 GUI 开发者日志开放。

公网页面右上角的服务状态按钮可查看本程序服务、PPO 官网最近可用状态、24 小时查询成功率、队列使用量、流控次数及最近状态变化。状态记录只查询最近 24 小时，初始最多显示 20 条；存在更多记录时可点击“加载更多状态记录”，每次再读取 20 条，读取完毕后按钮自动隐藏。这里只提供聚合数据，不返回车牌、证件、IP、设备标识或追踪编号。

使用 Nginx、Cloudflare Tunnel 等反向代理时，程序默认只在连接来自本机或 `PPO_TRUSTED_PROXIES` 列出的精确代理 IP 时读取 `CF-Connecting-IP`、`X-Real-IP`、`X-Forwarded-For` 或标准 `Forwarded`，查询和反馈会记录其中的真实客户端 IP。反向代理必须覆盖客户端传入的转发头，不能不加检查地原样追加；直连公网或局域网客户端伪造的转发头不会被信任。可设置 `PPO_TRUST_PROXY=false` 完全关闭此能力。

## 外部 API

内置网站和外部调用使用同一个接口：

```http
POST /api/v1/queries
Content-Type: application/json
X-Device-Id: 由调用方生成并持久保存的随机标识

{
  "requestId": "order-001",
  "plate": { "letters": ["أ", "ب", "ج"], "number": "1234" },
  "owner": {
    "type": "passport",
    "documentNumber": "EA1234567",
    "country": "10206",
    "foreignType": "foreign"
  }
}
```

匿名调用必须携带稳定、随机且至少 8 位的 `X-Device-Id`，用于流控和数据隔离。可选配置 `PPO_API_KEYS=key-one,key-two`，外部系统携带 `X-API-Key` 后识别为受信任调用并可读取全局历史；API Key 不绕过队列容量和熔断。浏览器中的外部站点如需跨域调用，还要配置精确来源白名单，例如 `PPO_CORS_ORIGINS=https://query.example.com`；默认不允许任意跨域来源。

主要接口：

- `POST /api/v1/queries`：提交查询
- `GET /api/v1/queries/:id`：查询详情和事件时间线
- `DELETE /api/v1/queries/:id`：取消排队任务
- `GET /api/v1/queue`：当前队列
- `GET /api/v1/history`：历史任务
- `GET /api/v1/events`：SSE 实时状态
- `GET /api/v1/health`：健康检查
- `GET /api/v1/status`：公开的脱敏服务状态和 24 小时指标
- `POST /api/v1/feedback`：提交建议反馈；`content` 必填，`phone`、`wechat`、`attachments` 选填。附件最多 3 个，单个 5 MB、合计 10 MB，只接受经过内容签名检查的 PNG、JPEG、WebP、PDF、TXT、LOG

## Admin 管理后台

桌面 GUI 主窗口右上角提供 `Admin` 入口，并使用仅存在于当前 Electron 会话的随机令牌免密进入。远程维护时，在同一服务端口访问 `/admin`（`/admin.html` 也可用），输入管理员密码登录。

首次使用请从桌面 GUI 的 Admin 页面点击“设置密码”。密码必须为 9～128 个字符，只保存随机盐和 `scrypt` 派生摘要，不保存明文。也可在首次启动前设置 `PPO_ADMIN_PASSWORD` 完成初始化。远程登录默认最多尝试 5 次/15 分钟；成功后使用 12 小时 HttpOnly、SameSite=Strict 会话 Cookie，所有修改类 Admin 接口额外验证 CSRF。修改密码会立即使现有远程会话失效。公网使用时务必通过 HTTPS 反向代理访问。

Admin 页面提供：

- 所有用户的实时运行/排队任务，包括完整证件、来源 IP、设备标识和追踪编号
- 每个查询请求的完整设备 ID、来源 IP、User-Agent，以及国家、地区、城市、运营商和时区等粗略 IP 归属信息
- 全部查询历史、官网原始错误及完整事件时间线
- 按车牌、完整或脱敏证件、追踪编号、任务编号搜索
- 按级别、事件名和任意结构化字段筛选日志
- 查询失败、查询成功、护照重试、流控、熔断、队列和服务启停快捷筛选
- 服务器、PPO 官网、成功率、队列和流控指标及状态历史
- 用户反馈的正文、可选手机号/微信号、截图或文件、访问页面及客户端信息，可搜索、预览/下载附件、备注并标记未读/已读/已处理/已归档

## 检查更新

GitHub 私有仓库的 Release 对未认证客户端固定返回 404，不能把仓库 Token 内置到安装包。正式分发时建议将发布仓库设为公开，或配置公开的 `PPO_UPDATE_MANIFEST_URL`；清单格式为 `{"version":"1.0.4","url":"https://下载页面或安装包地址"}`。开发者本机也可临时通过 `PPO_GITHUB_TOKEN` 检查私有仓库，但不要将 Token 写入 `.env` 后分发、提交源码或放进 CI 产物。

完整信息只在 Admin 管理后台显示；普通 GUI 查询页不再提供详细日志窗口。

## 数据位置

开发模式和打包后的桌面程序都保存在系统应用数据目录，不会写入安装包：

- SQLite：`data/ppo-query-hub.sqlite`
- Chromium/PPO 会话：应用数据目录下的 Electron `Partitions/ppo-query-engine/`
- 审计日志：`logs/audit-YYYY-MM-DD.jsonl`
- 官网异常诊断：`data/diagnostics/*.json` 和 `*.png`

SQLite 保存完整查询参数、客户端信息、反馈、来源、结果、服务状态及事件，便于按 `traceId`、车牌、设备 ID 或 IP 追溯；JSONL 日志每条记录严格占一个物理行，同时保存 UTC `timestamp` 与带时区偏移的服务器 `localTimestamp`。查询生命周期日志统一包含 `queryId`、`traceId`、阿拉伯车牌、脱敏证件、事件名和级别，并记录流控拒绝、队列已满、任务复用、熔断、护照格式重试、反馈和管理员登录事件及服务启停。

例如：

```json
{"timestamp":"2026-08-20T13:38:43.584Z","localTimestamp":"2026-08-20T16:38:43.584+03:00","level":"info","event":"query_completed","queryId":"qry_xxx","traceId":"tr_xxx","plate":"أ ف س 3413","documentMasked":"EC****02"}
```

查询超时、官网表单变化或提交按钮异常时，会额外保存当时官网页面的结构化快照和截图。诊断文件可能包含敏感信息，仅保存在本机应用数据目录，不通过公开 API 返回文件路径。手机端记忆的常用填写信息仅保存在该手机浏览器本地，可随时通过浏览器清理。

公网 IP 归属默认通过 `https://ipwho.is` 的 HTTPS 接口异步查询，并在 SQLite 缓存 30 天。只向该服务发送需要定位的公网 IP，不发送车牌、证件、反馈正文或联系方式；本机、局域网和保留地址不会外发。定位失败或额度用尽不会阻塞查询和反馈，可用 `PPO_IP_GEO_ENABLED=false` 完全关闭，或用 `PPO_IP_GEO_ENDPOINT` 切换兼容服务。IP 定位只能代表网络出口的近似国家/城市，不能当作用户精确位置。

历史队列默认显示当前设备最近 20 次查询，可通过“加载更多记录”按 20 条继续展开。全局历史、完整证件、详细日志和诊断目录统一迁移至受随机桌面令牌保护的 Admin 页面。

开发环境可运行 `./node_modules/.bin/electron scripts/smoke-initialize.cjs`，只检查 PPO 车辆表单及目标按钮是否可见，不填写证件信息，也不会提交真实查询。
